# Ratata (Frontend)

Ratata is a real-time multiplayer game frontend built with React. It features secure user authentication, real-time matchmaking lobbies, customizable game settings, and in-game state synchronization powered by WebSockets.

The backend for this project can be found here: [Rithesh-S/Ratata\_backend](https://github.com/Rithesh-S/Ratata_backend)

---

## How to Play: Rules and Regulations

To ensure fair play and a seamless multiplayer experience, Ratata enforces the following rules and mechanics based on its real-time architecture:

* **Lobby Requirements:** A minimum of 2 players is required to start a match. Only the designated "Room Creator" has the authority to initiate the game.
* **Room Access:** Players can only join private matches using a valid, 6-character room code generated by the host.
* **Match Execution:** Once the room creator starts the match, players transition from the Waiting Lobby to the active game grid.
* **Scoring System:** The objective is to dominate the grid. Players accumulate points through kills while minimizing their death count.
* **Match Abandonment:** Leaving an active match in progress is discouraged. Attempting to close or refresh the tab during an active game will trigger a browser warning to prevent accidental disconnection. Disconnecting early forfeits your current progress.
* **Match Conclusion:** Upon completion of the match timer or score limit, all players are redirected to the Match Results screen, which displays a final leaderboard sorted by total points.

## Customization Options

Ratata provides players with a tailored experience through extensive customization options, accessible via the Profile and Settings dashboards.

### 1. Profile Customization

* **Display Name:** Players can update their in-game username at any time. Changes are reflected immediately across the local session and database.
* **Avatar Upload:** Players can upload a custom profile picture. The image is processed via a `FileReader`, converted to a Base64 string, and stored locally for immediate rendering across the application. Uploads are strictly validated to accept only image formats under 5MB.

### 2. Control Mapping

Players can fully remap their keyboard inputs in the Settings menu to suit their playstyle. The game includes built-in collision detection to prevent assigning the same key to multiple actions.

* **Movement:** Map keys for Move Up, Move Down, Move Left, and Move Right (Defaults: Arrow Keys).
* **Action:** Map the primary shoot/attack key (Default: Space).
* **Interface:** Map the exit/pause key (Default: Escape).
* **Reset Functionality:** A single-click reset button restores all controls to their default mappings.

### 3. Audio Preferences

* **Global Volume:** An interactive slider allows players to adjust the master volume from 0 to 100%. Audio preferences are saved to local storage to persist across sessions.

## Key Features

* **Real-Time Matchmaking:** Synchronized game lobbies with countdown timers, player readiness tracking, and creator-controlled match starts using Socket.io.
* **Secure Authentication:** JWT-based protected routes with automatic token expiration handling and Axios interceptors for secure API communication.
* **Performance Optimized:** Implements local caching for game statistics (5-minute refresh intervals) and infinite scrolling via the Intersection Observer API for match history.

## Tech Stack

* **Framework:** React.js (Vite)
* **Routing:** React Router DOM
* **State Management:** React Context API
* **Real-Time Engine:** Socket.io-client
* **Styling & Components:** Tailwind CSS, PrimeReact, Lucide React
* **HTTP Client:** Axios
* **Notifications:** React Toastify

## Environment Configuration

To run this application, create a `.env` file in the root directory of your project and configure the backend URL:

```env
VITE_BASE_URL=http://localhost:5000

```

*(Replace the URL with your actual backend/socket server address).*

## Browser Storage Architecture

The application relies heavily on browser storage to minimize network requests and maintain active sessions.

### Local Storage (Persistent)

* `token`: JWT for authenticated requests.
* `userName` / `email`: Cached user credentials.
* `profilePic`: Base64 encoded user avatar.
* `controls`: JSON object containing mapped keybinds.
* `volume`: Global audio level setting.
* `cachedStats` / `statsLastUpdated`: Caching system for dashboard statistics.

### Session Storage (Temporary)

* `roomCode`: The 6-character identifier for the active match.
* `socketId`: The current Socket.io connection identifier.

## Installation and Setup

Follow these steps to run the application locally:

1. **Clone the repository and navigate to the project directory:**

```bash
git clone <your-repo-url>
cd ratata-frontend

```

2. **Install dependencies:**

```bash
npm install

```

3. **Configure the environment:**
Create a `.env` file in the root directory and add your `VITE_BASE_URL`.
4. **Start the development server:**

```bash
npm run dev

```

The application will typically be available at `http://localhost:5173`.
